# The Non-Linear Path of an Engineer

An animated, 12-slide talk for students about building a career that doesn't run in a straight line, from a backyard rocket to structural engineering, transportation data science, teaching and physics-informed AI.

**Live:** https://rezaghaeli.github.io/non-linear-path/

Created by [Reza Ghaeli](https://github.com/RezaGhaeli), P.Eng.

## Presenting

- **Next slide:** `→`, `Space`, or click the right side of the screen
- **Previous slide:** `←`, or click the left third
- **First / last slide:** `Home` / `End`
- **Full screen:** `F`
- **Phone or tablet:** swipe

It is a single static page (`index.html`) with no build step. The images are in `img/`.
